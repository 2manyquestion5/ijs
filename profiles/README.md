# Profiles

A profile is a user-side selection of applications, preferences and behavior.
It is currently a design concept, not an implemented profile-selection system.
The public starter composes ordinary Home Manager modules directly.

Possible future profiles include desktop essentials, development tools or a
smaller environment for a remote host. These are examples, not selectable names
or security guarantees. A host role composes host capabilities; a user profile
cannot authorize privileged services or group membership.

Reuse modules and preferences rather than copying desktop implementations.
See [architecture](../docs/architecture.md) for composition and
[the roadmap](../docs/roadmap.md) for current scope and later work.
