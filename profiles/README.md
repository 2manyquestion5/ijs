
# Profiles

Profiles are reusable collections of capabilities and configuration.

Planned profiles:
- desktop: graphical desktop essentials
- development: coding tools and workflows
- privacy: privacy-oriented application preferences
- portable: capabilities for an environment running on another host

A host may activate multiple compatible profiles.
Profiles should reuse modules and user preferences rather than
duplicate desktop-specific configuration.

Status: planned; no profiles are active yet.
